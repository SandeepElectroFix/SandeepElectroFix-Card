# Sandeep ElectroFix - Digital Business Card

Professional digital business card and service estimation platform for **Sandeep ElectroFix**, a premier electrical services provider based in Lucknow, Uttar Pradesh.

## 🚀 Features

* **Fully Responsive Design:** Seamlessly adapts to any screen size (Mobile, Tablet, Desktop).
* **Multi-Language Support:** Easily toggle between English and Hindi.
* **Smart Service Catalog:** Interactive service list with real-time pricing calculation.
* **Live Estimation:** Users can select services and get an instant price estimation.
* **PDF Export:** Generate and download professional service estimates as PDF files.
* **WhatsApp Integration:** Directly send service requests and estimates via WhatsApp.
* **Theme Customization:** Integrated Dark/Light mode support based on system preference.
* **Easy Management:** All business info, services, and galleries are managed via a single `config.js` file.
* **Location Services:** Built-in GPS/Location detection to calculate distance from the business center.

## ⚙️ Configuration Management

You don't need to edit HTML or CSS to update your business information. Simply edit the `config.js` file:

1. **Business Details:** Update phone number, WhatsApp, email, and social media links in the `business` object.
2. **Services:** Add or remove electrical services, change prices, or descriptions in the `services` array.
3. **Controls:** Enable or disable sections (like Gallery, Reviews, or QR code) using the `controls` object.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Responsive grid, flexbox, and glassmorphism design.
* **Vanilla JavaScript:** Core logic, state management, and calculation engine.
* **jsPDF & AutoTable:** For dynamic PDF estimate generation.

## 🚀 How to use
- **Reset:** Use the top "Reset" button to revert all cart selections, inputs, and settings to default (Phone's default language and theme).
- **Inquiries:** Select services, enter location, and use the "WhatsApp" or "PDF Download" buttons to proceed.
